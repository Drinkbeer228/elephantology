# Слонология

Академическая цифровая энциклопедия о слонах.

## О проекте
«Слонология» — академическая цифровая энциклопедия о слонах, объединяющая систематизированные материалы по биологии, анатомии, поведению, экологии, ветеринарии, эволюции и охране Elephantidae. Проект направлен на создание надежной, структурированной базы знаний.

## Редакционная модель
Каждая статья является единицей научного контента с формализованными метаданными. Материалы проходят этап проверки и структурирования. Статьи связываются между собой перекрестными ссылками для создания семантической сети знаний. 

## Модель доказательности
Уровни доказательности (`evidence_level`) характеризуют степень поддержки утверждения существующей литературой и отражают редакционную классификацию базы, а не являются самостоятельным доказательством истинности утверждения:
- `established`: Хорошо установлено (академический консенсус)
- `moderate`: Достаточная база (подтверждено рядом исследований)
- `limited`: Ограниченные данные (единичные наблюдения)
- `hypothesis`: Гипотеза (научное предположение)
- `contested`: Дискуссионно (существуют противоречивые мнения в научном сообществе)

## Источники
Энциклопедия опирается на следующие типы литературы:
- peer-reviewed journals
- научные книги
- статьи
- отчёты организаций
- стандарты
- официальные документы
- авторитетные справочные материалы

## Библиографическая политика
Статьи включают академические ссылки. Утверждения снабжены списком источников с указанием авторов, года, DOI или ISBN, чтобы читатели могли обратиться к первоисточникам.

## Метаданные статей
Все статьи используют строгую YAML-схему (Frontmatter):
```yaml
---
title: "Название статьи"
evidence_level: 'established' # Уровень доказательности
category: anatomy # Дисциплина
tags:
  - тег-1
  - тег-2
reading_time_min: 15
last_reviewed: 2026-08-24 # Дата последнего редакционного пересмотра
references:
  - id: doi/isbn
    title: "Название источника"
---
```

## Редакционный стандарт статьи (Слонология 2.0)
В рамках перехода к полноценной редакционной системе все 72 статьи постепенно приводятся к единой логике подачи материала:

1. **Краткое резюме** (вводный абзац)
2. **Ключевые сведения**
3. **Основной текст**
4. **Научная неопределённость** (что известно, что вероятно, что неизвестно)
5. **Связанные темы**
6. **Источники**
7. **Редакционный пересмотр** (указание статуса и даты пересмотра)

## Дорожная карта (Слонология 2.0 — Редакционная система)
Дальнейшее развитие проекта сфокусировано на качестве контента, а не на UI:
1. **Библиография** — переход к формату APA с указанием авторов, DOI, журналов.
2. **Глоссарий** — терминологический слой с перекрёстными ссылками на дисциплины и статьи.
3. **Стандарт академической статьи** — унификация структуры 72 статей.
4. **Система связанных материалов** — семантические перекрёстные ссылки.
5. **Аудит 72 статей** — редакционный контроль контента.
6. **Evidence level** — привязка статусов достоверности к реальным основаниям.
7. **SEO-аудит каждой статьи** — проверка метаданных и разметки.

## Структура проекта
```text
elephantology-wiki/
├── docs/                 # База знаний в Markdown (категории, glossary.md, bibliography.md, index.md)
├── src/                  # React Frontend (TypeScript)
│   ├── components/       # UI компоненты (ArticleCatalog, ArticleViewer и т.д.)
│   ├── lib/              # Утилиты, поисковый движок
│   └── main.tsx          # Точка входа React
├── public/               # Статические ресурсы (иконки, манифесты)
├── server.js             # Express Backend для middleware, SEO и fallback
└── prerender.js          # SSG утилита для пререндера статики
```

## SEO
Настроена генерация статических HTML-страниц (SSG) для обеспечения индексируемости (Googlebot-friendly) через скрипт `prerender.js`, который генерирует мета-теги и контент для краулеров. Также настроена автоматическая генерация `sitemap.xml`.
