# Живая библиотека — задачи в этом репозитории

Главная дорожная карта, принципы и галочки — в research-station:
https://github.com/Drinkbeer228/research-station/blob/main/docs/living-library/ROADMAP.md

Карточки ниже можно делать, не открывая другие репозитории. Сделали — в PR напишите «закрывает шаг N из ROADMAP research-station».
Принципы коротко: текст статей не менять, авторов и источники не выдумывать, интерфейс на русском, проверки соразмерные, сливать merge commit (не squash).

Этот репозиторий — источник статей (`docs/**/*.md`) и данных книг (`npm run build:library` → `dist/library/`). Статьи правятся как обычно, книги пересобираются при каждой выкладке.

## Карточки

- [ ] **2.5c [EL] до выкладки — сборка.** Файлы: `scripts/library/buildLibrary.ts`, `scripts/build-library.ts`.
  1. Книга, которая не прошла `validateBook`, всё равно записывается и попадает в каталог; ошибка только в отчёте. Сборка должна выходить с кодом 1 и такую книгу не писать.
  2. `build-library.ts` молча игнорирует неизвестные или кривые флаги (опечатка → значения по умолчанию). На неизвестный флаг — ошибка и код 2.
  - Проверки: `npx vitest run`, `npm run build` (70 книг, 0 ошибок KaTeX, 0 ошибок схемы).
