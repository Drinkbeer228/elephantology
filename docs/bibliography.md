# Библиография

Полный список научных источников, использованных в энциклопедии «Слонология». Источники сгруппированы по типу публикации.

## Редакционный стандарт библиографии
В энциклопедии внедрён строгий стандарт оформления источников. Для всех новых и обновляемых академических статей метаданные (YAML Frontmatter) должны включать поля в следующем формате (на основе APA):

```yaml
references:
  - id: doi_или_уникальный_идентификатор
    title: "Название статьи или книги"
    authors: "Фамилия И.О., Фамилия И.О."
    year: 2024
    journal: "Название журнала"
    volume: "Том"
    issue: "Выпуск"
    pages: "Стр-Стр"
    doi: "10.1xxx/xxx"
    isbn: "978-..."
```
Этот подход позволяет читателям независимо идентифицировать источник.
