## 1. Архитектура движка диалогов и «сарафанного радио» (`dialogueRules.ts`)

Вместо жёстких ветвящихся деревьев диалоги и реплики на ходу (`src/station/speech.ts`) работают как **движок правил по снимку фактов мира (`WorldFactsSnapshot`)**. При обращении к персонажу или входе в зону триггера движок фильтрует правила по предикатам `when`, отбрасывает сработавшие недавно по `npc_memory` и выбирает правило с наивысшим весом конкретности `specificity`.

### 1.1. Контракт типов для TypeScript
```ts
export type DialogueChannel = 'bark' | 'dialog';

export interface FactCondition {
  fact: string; // ключ из WorldFactsSnapshot (например, 'handsClean', 'pH_last', 'season')
  op: '==' | '!=' | '<' | '<=' | '>' | '>=' | 'includes';
  value: string | number | boolean;
}

export interface ActionChoice {
  id: string;
  label: string;                 // текст кнопки-поступка игрока (до 3 вариантов)
  requires?: FactCondition[];    // условие доступности (например, наличие веток ивы из Оранжереи)
  setFacts?: Record<string, string | number | boolean>;
  trustDelta?: Record<string, number>; // изменение отношения NPC (включая свидетелей)
  specialtyDelta?: { field?: number; lab?: number; clinical?: number };
  responseText: string;          // ответная реплика персонажа после поступка
}

export interface DialogueRule {
  id: string;
  npcId: string;
  channel: DialogueChannel;
  specificity: number;           // 100 = авария/ТБ, 70 = событие дня/слух, 40 = прогресс, 10 = фон
  when: FactCondition[];
  cooldownHours?: number;
  once?: boolean;
  text: string;
  choices?: ActionChoice[];
}

```

### 1.2. Шкала доверия и «сарафанное радио» (`12:45–14:00`)

* **Уровни отношения (`npcTrust` от `-100` до `+100`):**
* `< -20` (**Настороженность**): сухие односложные реплики, отказ в неформальных подсказках;
* `-20 … +39` (**Рабочий нейтралитет**): стандартный учебный тон;
* `+40 … +79` (**Уважение**): персонаж делится профессиональными тонкостями и предупреждает о проверках;
* `≥ +80` (**Доверие / «Свой человек»**): открываются личные вечерние разговоры; у Дмитрия Викторовича Таранина заголовок плашки в диалоге меняется на **«Димон»**.


* **Механика слухов:** поступки стажёра на утренней смене записываются в `WorldFactsSnapshot.dailyEvents` (например, `bent_shovel_morning`, `helped_forage_chain`, `resolved_apple_dispute`). В обеденное окно (`12:45–14:00`) в Столовой и на лавках сквера у **Зои**, **Галины Петровны**, **Пети** и однокурсников автоматически активируются правила с `specificity: 70`, через которые новость узнают даже те сотрудники, которых не было рядом при событии.

## 2. Три ключевых межведомственных конфликта (Деревья выбора-поступка)

Конфликты строятся вокруг столкновения «Полевиков» и «Кабинетных» — без «правильных» морализаторских лекций, через реальную цену каждого решения для слонов и людей.

### 2.1. Конфликт А: «Яблоки против лактатного ацидоза» (Алиса vs Таранин)

* **Условие запуска:** II–III семестр; в Эколабе зафиксирован `pH < 6,2` у Одри/Марго, одновременно в Слоновнике идёт плановая расчистка стоп у стенки EHS.
* **Суть спора:** Алиса требует немедленно убрать яблоки и бананы из ведомости склада, чтобы не сорвать ферментацию слепой кишки в острый ацидоз (`pH < 5,8`). Дмитрий Викторович возражает: без понятного пищевого подкрепления слонихи отказываются фиксировать ногу на подставке.
* **Варианты поступка игрока:**
1. *«Поддержать полный запрет Алисы без замены»:*
* **Эффект:** `trustDelta: { alisa: +15, taranin: -15 }`, `specialtyDelta: { lab: +2 }`.
* **Последствие:** кислотность стабилизируется, но в следующую смену Слоновника Марго и Одри неохотно подают ногу у стенки EHS (штраф ко времени фиксации).


2. *«Встать на сторону киперов и принести яблоки со склада»:*
* **Эффект:** `trustDelta: { taranin: +10, alisa: -20, vera: -10 }`, `specialtyDelta: { field: +1 }`.
* **Последствие:** тренинг проходит быстро, но к вечеру `pH` падает до `5,8` — требуется экстренная корректировка рациона и снятие животного с концентратов.


3. *«Принести из Оранжереи ветки ивы, топинамбур и кубики моркови»* (доступно, если заготовлено в Оранжерее):
* **Эффект:** `trustDelta: { alisa: +20, taranin: +20, vera: +10 }`, `specialtyDelta: { field: +1, lab: +1 }`, `setFacts: { apple_dispute_resolved: true }`.
* **Последствие:** некалорийные маркеры в связке с кликером сохраняют мотивацию слоних у стенки EHS и возвращают `pH` в норму `6,5–6,8`.





### 2.2. Конфликт Б: «Утренний перегон против чистой пробы» (Ира vs Таранин)

* **Условие запуска:** утреннее окно `05:30–07:30` в день сдачи копрограммы перед выпуском стада в парк.
* **Суть спора:** лаборантка Ира просит задержать открытие шибера на выгул ради свежего утреннего болюса Одри без примеси песка и мочи; Таранин настаивает на точном графике перегона, пока стадо не начало нервничать у ворот.
* **Варианты поступка игрока:**
1. *«Попросить киперов придержать ворота на 20 минут»:*
* **Эффект:** `trustDelta: { ira: +15, taranin: -10 }`.
* **Последствие:** проба идеально чистая, но Одри нервничает у шибера (`run.warnings +1`).


2. *«Открыть перегон строго по расписанию»:*
* **Эффект:** `trustDelta: { taranin: +10, ira: -15 }`.
* **Последствие:** стадо вышло вовремя, но утренние болюсы затоптаны — сдачу анализа в Эколабе приходится переносить на завтра.


3. *«Взять совок и отобрать пробу в первые 10 минут утренней дачи сена»:*
* **Эффект:** `trustDelta: { taranin: +15, ira: +20, alisa: +10 }`, `setFacts: { clean_morning_sample: true }`.
* **Последствие:** болюс перехвачен до выхода стада, график перегона не сорван ни на минуту.





### 2.3. Конфликт В: «Вето на сырую партию фуража» (Вера Павловна vs Склад и разгрузка)

* **Условие запуска:** утренняя приёмка фуража (`06:00–07:30`); при проверке партии игольчатым влагомером прибор показывает `19%` (при норме `≤ 14–16%`) и очаги серой плесени внутри тюков.
* **Суть спора:** машина уже частично разгружена; водитель Гена и грузчики устали и предлагают «просто перебрать верхний слой», тогда как Вера Павловна требует полного возврата машины из-за угрозы тимпании и токсического энтерита.
* **Варианты поступка игрока:**
1. *«Поддержать вето Веры Павловны, помочь погрузить тюки обратно и открыть резервный сухой ангар»:*
* **Эффект:** `trustDelta: { vera: +25, galina: +10, gena: +5 }`, `specialtyDelta: { clinical: +2 }`, `setFacts: { wet_hay_rejected: true }`.
* **Последствие:** тяжёлая физическая работа с утра, но стадо защищено от взрывного метеоризма.


2. *«Уговорить оставить партию и перебрать на глазок»:*
* **Эффект:** `trustDelta: { vera: -25, galina: -15 }`.
* **Последствие:** через 6 часов у одной из слоних начинается метеоризм, стажёр получает выговор по ТБ и санитарии.

## 3. Матрица «Этограммы» для Полевого планшета (`6 × 5`)

Вкладка **«Этограмма»** заполняется не из текста учебника, а **живыми штампами**: игрок наблюдает поведение слона вживую (через бинокль с вышки или настила, у стенки EHS или на ночном обходе) и фиксирует совпадение признаков.

| № | Состояние в Этограмме | Уши | Хвост | Хобот | Ноги и корпус | Акустика / Звук | Где поймать вживую |
| --- | --- | --- | --- | --- | --- | --- | --- |
| **1** | **Расслабленный комфорт и покой** | Медленные, ритмичные взмахи (`6–10/мин`) при температуре `> +20 °C`. | Спокойно свисает или лениво отмахивается от мух. | Расслабленно опущен, кончик опирается на землю или перекинут через бивень. | Поочерёдная разгрузка одной из задних ног (опора на зацеп). | Тихий низкий контактный рокот (`14–24 Гц`), урчание ЖКТ. | Парк (после купания) или Слоновник днём. |
| **2** | **Игровое поведение** *(Одри)* | Широко расправлены, энергичные хаотичные взмахи. | Приподнят дугой, кисточка распушена. | Подброшен вверх, обхватывает ветки, комья грязи или кепку кипера. | Прыжки на месте, мягкое бодание курганов или брёвен. | Короткие звонкие трубные вскрики и фырканье. | Тренировочный вольер (после выдачи обогащения) или грязевые ванны. |
| **3** | **Скрытая тревога и напряжение** | Замирают под углом `90°` (*Listening Freeze*) или прижимаются к шее. | Неподвижно прижат к промежности. | Поднят S-образно для забора пробы воздуха (*Periscope*), кончик замирает. | Весь корпус замирает, переминание с ноги на ногу прекращается. | Полная тишина — внезапный обрыв контактного рокота стада. | Северный настил при резком шуме техники или ночью в грозу. |
| **4** | **Абдоминальная боль / Колики** *(Претти)* | Вяло опущены, не реагируют на тихий оклик кипера. | Плотно поджат, возможны резкие удары хвостом по паху. | Кончик хобота зажат в зубах или упирается в пол (*поза Soost*). | Стернальная укладка на грудину, скрещивание задних ног, частые «лёг — встал». | Тяжёлое прерывистое сопение, отсутствие шумов в левой ямке. | Финальное ночное дежурство IV семестра (Слоновник). |
| **5** | **Дискомфорт стоп и суставов** *(Претти)* | Складываются в плотный V-образный треугольник при подъёме ноги. | Напряжён, отводится в сторону при переносе веса. | Ощупывает больное запястье или опирается хоботом о барьер. | Вынос больной левой передней вперёд на разгрузку, асимметрия шага. | Короткий низкий стон или глухое постукивание подошвой о грунт. | Стенка EHS при санации стоп или осмотре ОДА в Клинике. |
| **6** | **Предупреждение и ложная атака** *(Марго)* | Резко развёрнуты в стороны (визуальное увеличение головы). | Поднят вертикально вверх. | Свёрнут внутрь под подбородок или резкий удар кончиком о землю (*Trunk-Bounce*). | Голова высоко поднята (*Head-High*), резкий выпад на `2–3` шага и остановка. | Резкий металлический трубный рев или хлопок хоботом о землю. | Утренняя раздача корма при нарушении ранга или дистанции `< 30 м` в парке. |

## 4. Протокол ночного дежурства, гроза и мини-игра «Счёт овец»

Ночная смена (`20:00 – 06:00`) проверяет выдержку стажёра и знание биоритмов стада:

* **`20:00` — Вечерняя раскладка:** подвешивание сена в медленных кормовых сетках (чтобы слоны не съели всё до `21:00` и не забили желудок песком от ночного голода).
* **`21:30` — Световой режим:** перевод ангара в мягкий янтарный или тёмно-красный спектр (`< 15 люкс`). Включение яркого белого фонаря в глаза спящему стаду вызывает панический рывок.
* **`23:00 – 04:00` — Контроль фаз сна (обход по верхней галерее каждые `45–60 мин`):**
* Стоячий медленноволновый сон (*SWS*) чередуется с боковой *REM*-укладкой на песчаных курганах (`40–50 см` в стационаре, `80–120 см` в Зимнем ангаре).
* **Правило 90 минут:** если возрастная Претти лежит на одном боку дольше `90 мин`, кипер тихим щелчком или мягким голосом с галереи побуждает её сменить бок или встать, предотвращая сдавливание полой вены и ателектаз нижнего лёгкого.
* **Дисциплина тишины:** запрещён лязг лопат, цепей и задвижек после `22:00`.



### 4.1. Инцидент «Ночная гроза и дизель-генератор»

* **Триггер:** в ночь дежурства (III–IV семестр) грозовой фронт обесточивает линию кампуса, и на хоздворе автоматически запускается аварийный дизель-генератор.
* **Физиологический конфликт:** низкочастотный гул дизеля (`20–60 Гц`) накладывается на диапазон инфразвукового общения слонов (`14–24 Гц`). Стадо вскакивает с курганов в фазе *Listening Freeze*, отказывается ложиться и начинает беспокойно раскачиваться (*weaving*).
* **Цепочка действий игрока:**
1. Спуститься в щитовую у хоздвора (`toggle_power`), перевести питание ангара на бесшумные аккумуляторы с янтарными диммерами и заглушить дизель.
2. Подняться на смотровую галерею Слоновника и через интерком спокойным ровным голосом подать сигнал безопасности.
3. Спустить с галереи дополнительную сетку с веточным кормом для снятия остаточного напряжения.



### 4.2. Мини-игра «Счёт овец» (`nap_minigame`)

* **Условие:** ночью в дежурке Слоновника, когда все три слонихи улеглись спать, игрок может сесть на лавку и нажать **«Прикорнуть на посту»**.
* **Механика:** по тёмному экрану дежурки через равные (постепенно ускоряющиеся) интервалы прыгают силуэты овец; игрок нажимает `Пробел` / клик в момент прыжка.
* **Исход:**
* **Удержание ритма (`≥ 15` точных нажатий):** стажёр дремлет чутко — время ускоряется до следующего окна обхода (`45 мин`) или моментально прерывается при любом тревожном звуке из зала.
* **Сбой ритма (3 пропуска подряд):** стажёр проваливается в глубокий сон до `06:00`, пропускает ночной обход и просыпается в неубранном зале под строгий разбор Дмитрия Викторовича (`run.warnings +2`).

## 5. Кульминация IV семестра: «Ночной приступ острых колик у Претти»

Финальное практическое испытание перед допуском к Диплому разворачивается в ночную смену конца IV семестра:

1. **Обнаружение (Обход на галерее):** в `01:30` стажёр замечает, что в деннике Претти нет свежих болюсов, слониха не ложится на курган, стоит с опущенной головой, поджатым хвостом и зажатым в зубах кончиком хобота (*поза Soost*).
2. **Первичная диагностика:** аускультация левой голодной ямки фиксирует полную тишину перистальтики (`> 2 часов`), слизистые бледно-розовые, дыхание учащённое и поверхностное.
3. **Экстренный вызов и развёртывание поста:**
* Стажёр поднимает тревогу в Клинику — прибегают **Вера Павловна**, санитар **Артём** и однокурсница **Соня**.
* Пока Вера Павловна вводит спазмолитик и анальгетик (флуниксин / бускопан) в заушную вену, стажёр вместе с Артёмом готовит клизменный пост: подогревает `50–100 литров` физраствора строго до **`+38 °C`** (проверка термометром — холодный раствор усилит спазм, горячий вызовет ожог слизистой), подключает помпу Рида и распрямляет армированный зонд длиной `2,5–3 м`.


4. **Развязка и оценка:**
* При точном соблюдении последовательности и температуры раствора через `20 минут` в левой голодной ямке возобновляется урчание перистальтики и отходят газы.
* Вера Павловна ставит высшую клиническую отметку в зачётную ведомость, а **Борис Сергеевич** на следующий день допускает стажёра к итоговому экзамену на Кафедре и вписывает этот случай в персональную характеристику к Диплому.



```
