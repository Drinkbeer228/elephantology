# Пакет постановщиков задач (Issues / PR 5.1 – PR 5.8) для реализации Фазы 5

Этот документ содержит 8 самодостаточных промптов-задач для поэтапной реализации Фазы 5 в репозитории `Drinkbeer228/research-station`. Каждый шаг соответствует одному изолированному Pull Request с сохранением архитектурного правила **«Один ключ — один писатель»**, бюджета стартового бандла (`≤ 14 КБ gzip`) и зелёного прогона всех существующих юнит- и e2e-тестов.
